# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. In short: be respectful and constructive, assume good faith, welcome newcomers, and
keep discussions about the work. Harassment, personal attacks and discrimination are not tolerated.

Report unacceptable behaviour privately to the maintainers through
[GitHub](https://github.com/myfoxit) (direct message or a private security advisory if you prefer
the confidential channel); reports are handled discreetly.
